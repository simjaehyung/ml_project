기존 접근 — 예측 1건
예약 1건 입력
↓
취소 확률 출력
↓
끝.
증상: "이 예약이 취소될 것 같다"
구조적 질문들은 여전히 답 없음
우리 접근 — 운영 인텔리전스
취소 예측 엔진 (cancel_probability)
  │
  ├── 채널 × ADR × 취소율 → 실효 수익
  │     "어느 채널에서 어떤 예약을 받을 것인가"
  │
  ├── ADR + 체류 + 특별요청 + cancel_prob
  │     "이 예약을 지킬 것인가, Flexi로 보낼 것인가"
  │
  └── meal × cancel_probability
        "식재료를 얼마나 발주할 것인가"
핵심: 세 방향 모두 새로운 ML 모델이 필요 없다.
하나의 엔진이 세 가지 운영 문제를 동시에 푼다.

계산 구조

──────────────────────────

Direct      ADR €105 취소 18% → €86.1
Corporate   ADR €88   취소 9% → €80.1
GDS         ADR €112 취소 28% → €80.6
lead_time 교차 분석
Online TA × lead_time > 90일
  → 가격 탐색형 · 더 싼 딜 나오면 이탈
Online TA × lead_time < 14일
  → 목적 있는 막판 예약 · 이탈 낮음
이 분석이 바꾸는 것
  • 1
    마케팅 예산 배분 실효 수익이 낮은 채널 의존도 줄이기 — 액면 ADR이 아닌 실효 ADR 기준
  • 2
    Direct 채널 육성 투자 ADR ↑ + 취소율 ↓ 의 복리 효과를 데이터로 보여준다
  • 3
    Flexi 오퍼 우선순위 고취소 채널 예약에 먼저 Flexi를 제안 — 채널 전략과 운영 전술의 연결

App Layer 2 — 신규 예약 Flexi 라우팅
기존 vs 정밀 오버부킹
기존 — 블라인드 오버부킹
과거 평균 취소율 37% → 일괄 초과판매
→ 어느 예약이 취소될지 모르고 찍는 것
Flexi — 정밀 오버부킹
모델 → "이 예약들이 취소 가능성 높다"
→ 그 자리에만 Flexi 예약 추가 판매
→ 예측 정확도가 높을수록 walk 없이 방을 채운다
할인율 공식
5% + (위험 − 0.5) × 26%
위험 0.75 → 11.5%
목표 지표
walk_rate < 2%
net_gain > 0

STANDARD RATE
€120 / 박
✓ 즉시 객실 확정  ·  ✓ 무료 취소
FLEXI RATE
−15%
€102 / 박
✓ 동일 등급 객실   ℹ 배정: 체크인 전날
✓ 미배정 시 전액 환불 + 보상

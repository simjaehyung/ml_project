예측 모델이 아니라,
데이터로 자라는 의사결정 인프라를 만들었습니다.

호텔에 핏한 예약 데이터를 모으고, 그 데이터로 자라는 ML 예측(오버부킹 · 그 외 도메인)으로 수익과 경영 안정성을 극대화하는 데이터 수집 인프라. 오버부킹은 그 첫 도메인일 뿐.

실데이터(Kaggle · 우리 두 호텔의 실제 2년 기록) · 누적창 79주 · Bootstrap 95% CI · 하이쿠 미사용
  • 콜드스타트(데이터 거의 없음)에선 단순모델(LR)이 우위 — 빠르게 올라 plateau ~0.78
  • 약 5.4만 건(W·84주)에서 LightGBM이 통계적으로 추월 → 끝까지 유지
  • 그 사이 구간은 구분 불가(tie) — CI가 겹치면 "교차"라 부르지 않는다(robust)
  • full-data 최종 PR-AUC 0.820 (Dummy 0.387 대비 2.1배)

"성장형 시스템은 모델을 고정하지 않는다 — 데이터량이 최적 모델을 정한다."

멘트: "정적 비교표가 아니라 데이터가 쌓이며 승자가 바뀌는 동적 곡선입니다. 우리는 모델을 고르지 않습니다 — 데이터가 모델을 고르게 합니다. (정직: W는 여름 편중 test셋 의존값)"

3 · 의사결정 → 기대효과 → 보상

위험도로 몇 개를 오버부킹하고, 빗나가면 어떻게 보상하나 가정 아님 · 실데이터 기대값

E[순이익(K)] = 채운 방 수익 − E[walk 보상·평판] · 모델 위험도 기반 (overbooking_ev.py) · 일일코호트 162 · ADR €108 · K*≈38~41
  • 결정 원리: 한계비용 = 한계수익 (호텔 RM 표준 · 업계 5~15%)
  • risk-based가 RevPAR↑ · 결정권은 매니저 보유(GDPR Art.22)
  • 예측 빗나가 체크인 충돌 → walk(타 호텔 이전)
  • walk 보상 표준: 동급/상위 + 첫날 + 교통 + 굿윌 · 규제 없음(선불 환불만 의무)

⚠️ 비용비(빈방:walk) 미지수 → sweep. 평판 포함 시 walk가 더 비싸 비용비 거꾸로일 수 있어 → 보수적 오버부킹이 정답. (Hyatt: 첫날+교통 · Marriott: $200+14만pts)

정직(pin): "곡선은 가정이 아니라 모델 위험도로 계산한 기대값입니다. 단 빈방 vs walk 비용비는 미지수라 범위로 제시하고, 평판을 넣으면 보수적 오버부킹이 맞습니다."
작동 증거 ② 심화 · 협상 데이터로 보상을 정한다

페르소나가 아니라 체계화된 피처로 가격대를 찾는다

가격대를 정하는 두 힘

  • 하한 — 손님 만족 (너무 낮으면 불만)
  • 상한 — 평판 비용: 별점 1↓ = 매출 5~9%↓, 부정리뷰 3건+ → 79%가 예약 안 함

피처 → 보상 차등 (근거 있음)

  • 인원수 多 → 대체 숙소 확보 난이도↑
  • 예약 임박 → 대안 부족 → 불만↑
  • 등급/채널 → 로열티별 차등 (브랜드 실재)
  • ※ 국적은 차등에서 배제 (차별 방지 · S7)

1차 증거: walk 협상 시뮬 D 아키타입 €46 (≈ ADR 42%) — 업계 보상과 같은 자릿수. 이 (위험도→오퍼→수락→취소) 튜플이 ML②가 키우는, 세상에 없던 데이터.

멘트: "우리는 손님을 캐릭터로 안 봅니다. 인원·예약시점·세그먼트라는 피처로 적정 가격대를 찾습니다. €46는 ADR의 42%로 업계 보상과 같은 자릿수입니다(정확 일치 아님)."
4 · 왜 믿을 수 있나 · 집중 정산

의심에 정면으로 답한다 — 윤리 · 법률 · 효과

윤리 — 국적 차별

국적이 위험도 1위 피처. → 예측엔 쓰되 행동 차등엔 배제. ablation: 완전 DROP −5.0%(유의 손실)이나 is_domestic 절충은 −1.0%(무손실)로 차별 광학+top10 누수 소멸. 사전동의·매니저 승인 필수.

법률 — 우회로

한국 숙박업은 오버부킹 규제 공백. 우리 Flexi는 예약 시점 사전 동의 구조 → '계약 불이행'이 성립 안 함. 강제 배정·자동 발효는 금지선.

효과 — 시뮬 ≠ 현실

정량 주장은 실데이터가 책임(성장곡선 S3). 협상 시뮬은 "수집 인프라 시연"이지 현실 증명 아님. 현실 검증은 실배포 로그의 몫 — 정직하게.

정직 한계: 국적을 빼도 ADR·세그먼트 상관 피처로 간접 차별 잔존 가능 — disparate impact 측정은 6일 범위 밖, "한계"로 명시.

멘트: "앞에서 핀으로 찍어둔 의심들을 여기서 정산합니다. 국적은 예측엔 써도 차등 대우엔 배제하고, ablation으로 성능 비용을 쟀습니다. 한계를 먼저 드러내는 게 신뢰를 높입니다."

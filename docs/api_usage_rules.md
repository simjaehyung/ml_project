## 0. 한 줄 원칙

> **"가장 싼 모델로, 스모크 먼저, 측정하며, 목표에 맞는 만큼만."**
> 예산이 작다(~₩10,000 ≈ $7). 호들갑 떨 규모는 아니지만, 무한 루프·과도한 모델·검증 없는 대량 실행만 피하면 된다.

## 2. 모델 선택 규칙 (★ 핵심)

| 용도 | 모델 | 근거 |
|------|------|------|
| **모든 대량 sim (예약·협상·취소)** | **`claude-haiku-4-5-20251001`** | `agents.py:22 MODEL` 이미 설정됨. 페르소나 추론 + tool_use에 충분. 최저가. |
| 품질 쇼케이스(발표용 단발) | Sonnet 4.6 | 필요 시 **소수 호출만**. 재형님 curl 테스트가 sonnet이었지만 대량엔 부적합. |

**규칙:** 대량 실행 전 "이게 목표를 만족하는 가장 싼 모델인가?"를 먼저 답한다. Haiku 출력 품질을 스모크에서 눈으로 확인하고, 부족할 때만 상향.

---

## 3. 토큰·호출 가드레일

- `max_tokens` 이미 캡: 예약 추론 1024 / 최종 응답 256 (`agents.py:151,224`). **늘리지 말 것.**
- **스모크 먼저:** 대량 전 반드시 1 페르소나 · 1 라운드로 테스트
  ```
  python -m llm_sim.run_simulation --agents ana --rounds 1
  ```
  → 정상 + 품질 확인 후에만 `--agents all --rounds N`
- **측정:** 응답 `usage`(input/output tokens) 로그로 1회 비용 파악 → 대량 비용 외삽
- **무한 루프 금지:** 라운드 수·페르소나 수를 명시. 자동 재시도 루프에 상한.

---

## 4. 비용 외삽 (대략)

Haiku 4.5 ≈ $1/MTok(in) · $5/MTok(out) 수준(정확치는 콘솔 확인). 예약 1건 사이클(tool_use 2~3콜, ~2–6k in + ~1k out) ≈ **$0.01~0.015**.

| 시나리오 | 추정 비용 |
|----------|----------|
| 스모크 (1 페르소나 1라운드) | ~$0.02 |
| 5 페르소나 × 1라운드 | ~$0.07 |
| 5 페르소나 × 10라운드 (50건) | ~$0.7 |
| **$7 한도 내 최대** | **수백 건 예약 사이클** |

→ 예산 제약은 생각보다 **느슨**하다. 발표 데모(수십 건)는 넉넉. 다만 **스모크→측정→확대** 순서는 지킨다.

---

## 5. 비용 절감 옵션 (선택)

- **프롬프트 캐싱:** 페르소나 간 system 프롬프트가 반복되면 `cache_control`로 input 토큰 재사용 → 입력비 절감. (반복 호출 많을 때만 도입)
- 불필요한 reasoning 출력 줄이기: 데모에 필요한 "생각" 노출만, 장황한 출력 자제.

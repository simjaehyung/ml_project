# v24 — 보상값 리스본 재정초 (상황별 표)

> 작성: 2026-06-07. **주의:** 1단계 워크플로우의 웹 리서치(리스본 ADR·EU 보상법)가 **세션 한도로 실패** → 아래 리스본 시세·법규 수치는 **내 지식 기반 추정(≈)이며 발표 전 1차 출처 확인 필요**. 내부 데이터(우리 데이터셋 ADR·기존 삼각측량)는 실측.
> 지시 반영: **LLM 협상 갈래(€46) 핵심 제외**(추후 보강용으로만), **업계 관행 + 빈방 기회비용** 두 갈래를 **실제 리스본 방값**으로 구체화. 상황별 표 작성.

---

## 0. 한 줄 요약
> 보상 ≈ **동급 호텔 1박 요금(리스본 등급·계절별) + 교통비 + 성의**. 우리 데이터셋 ADR(€88~117, 2015–17)을 현 리스본 시세(≈€110~260, 등급·계절)로 올려 잡으면, **상황별 권장 보상 €약 90~300**. 두 갈래(업계 첫날보상·빈방 기회비용)가 모두 **≈1×ADR**에서 만나 근거가 단단함.

## 1. 기준 — 실제 리스본 호텔 1박 요금 (ADR, ≈·확인 요)

| 등급 | 비수기/평시 | 성수기·이벤트(여름·Web Summit 등) |
|------|-----------|--------------------------------|
| 3성 (시내) | ≈ €85~130 | ≈ €130~170 |
| 4성 (시내) | ≈ €120~180 | ≈ €180~260 |
| 5성 (시내) | ≈ €250~380 | ≈ €380~600 |
| 알가르브 리조트(4성) | 겨울 ≈ €60~100 | 여름 ≈ €150~300 |

- 리스본은 봄·여름 + 11월 Web Summit 시즌에 요금이 **2~3배**까지 뛴다(성수기 보상도 그만큼 상향이 관행).
- ※ 위 수치는 추정 — STR/관광청/예약플랫폼 리포트로 확정 필요(세션 한도로 자동 리서치 미완).

## 3. 두 갈래 재정초 (LLM 제외)

| 갈래 | 값(데이터셋) | 값(현 리스본 ≈) | 근거 |
|------|-----------|----------------|------|
| **(가) 업계 첫날 보상** | ≈ €105 (1×ADR) | €110~260 (등급·계절) | walk 시 동급/상위 호텔 **첫날 숙박비** 대납이 업계 표준 (+교통+성의) |
| **(나) 빈 방 기회비용(상한)** | ≈ €105 (1×ADR) | €110~260 | 못 판 방의 회복 불가 손실 = 1×ADR. 호텔 이익 상한선 (newsvendor c_fn) |
| (참고·제외) LLM 협상 하단 | €46 | — | 합성 협상 수락 하단. **핵심 근거에서 제외**(추후 실데이터로 보강 시 재투입) |

→ 두 **실(實)근거** 갈래가 모두 **≈1×ADR**에서 수렴. "한 사람 주장이 아니라 업계 관행과 회계(기회비용)가 같은 값을 가리킨다"가 메시지.

## 5. 정직 각주 (발표 시)
- 리스본 시세 수치는 **추정·확인 필요**(자동 리서치 세션 한도로 미완). 데이터셋 ADR은 실측.
- 표는 **권고치** — 실제는 호텔의 진짜 비용비 + 보정 확률(calibration)로 조정.
- EU/포르투갈: 호텔 walk는 항공(EC261) 같은 **강제 정액 보상 없음** → 계약·소비자법상 "동급 대체숙소+환불+합리적 보상"이 기준. 우리 표는 그 관행 범위 안.

## 6. 발표 반영 (덱)
- **S7(보상 — 세 갈래 → 두 실근거)**: 업계 첫날보상·빈방 기회비용이 **≈1×ADR**에서 수렴(LLM은 "추후 실데이터로 보강할 씨앗"으로 한 줄).
- **S8(상황별 표)**: §4 표를 **큰 표**로(키워드/숫자만), 설명은 노트로. "리스본 실가격 기준 상황별 보상."

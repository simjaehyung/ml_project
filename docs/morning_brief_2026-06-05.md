## 0. 한 문단 요약 (30초)

**최종 추천 = `v15_hybrid` (presentations/Hotel No-Show DSS v15_hybrid.html).** 이전 브리핑이 권고했던 "v14 base + variantA/B의 국적 ablation 수치 graft + variantB 카피 톤 이식"이 **v15에 이미 전부 반영됐다.** 즉 v15는 4종을 비교해서 고른 게 아니라, 4종의 강점만 합쳐 만든 통합본이다. 핵심: ① 국적 ablation 구체 수치(완전 DROP −5.0%·`0.8189→0.7783`·CI 분리 / is_domestic 절충 −1.0%·`0.8107`·CI 겹침)가 **S7 집중블록에 그대로 탑재** — 교수 지적 #4(국적 차별)를 닫는 최강 방어 카드. ② 정직성 핀(S3 국적→S7 / S4 체리피킹·국적 / S5 가정아님)이 모두 S7로 회수되는 규율 완비. ③ lock 수치(W≈5.4만·84주 / full 0.820 / Dummy 0.387 / 2.1배 / 운영임계 0.65 / walk €46≈42% / K*≈38–41·비용비 sweep / 별점·리뷰 평판 / GDPR Art.7·Art.22) **전부 검증 통과.** ④ Pretendard 웹폰트는 progressive enhancement(CDN 죽어도 시스템 폰트로 캐리), 발표자 노트(N키)·진행바·라이브 데모 Plan B/C 폴백까지 포함. **결론: 본은 v15로 확정 권고. 4개 변형은 백업·레퍼런스로 보존. 오늘 남은 건 본문 수정 5건(아래 §3)뿐 — 30~40분.**

## 2. 최종 추천 = v15_hybrid — 왜 4종보다 나은가

**v15는 "5번째 후보"가 아니라 "4종의 결론"이다.** 이전 브리핑의 핵심 권고는 "v14의 13슬 엔진 + variantA/B의 S11 ablation 수치 + variantB의 카피 톤만 이식"이었고, v15_hybrid는 그 graft를 한 파일에 끝낸 결과물이다. 따라서 v15를 고르면 4종 각각의 강점(정본의 thesis 일관성·핀 구조, A의 압축 수치 카피, B의 정직 서사 톤)을 동시에 얻으면서, 각 변형의 약점(A의 수치만 좋고 흐름 약함, B의 슬라이드 엔진 이탈, C의 구버전 수치)을 모두 피한다.

구체적으로 v15만 동시에 충족하는 것: ① **교수 지적 #4를 측정 수치로 격상** — S7에 완전 DROP −5.0%(CI 분리=유의 손실)와 is_domestic 절충 −1.0%(CI 겹침=무손실)를 나란히 두어 "차별 광학 제거 + 신호 보존 + top10 누수 소멸"을 한 칸에 정산. ② **정직성 3핀이 전부 S7로 회수** — 추상 약속이 아니라 슬라이드 동선으로 규율됨. ③ **폰트·데모 실행 리스크 동시 차단** — Pretendard CDN이 죽어도 시스템 폰트 폴백, 라이브 데모 실패 시 Plan B(녹화)/Plan C(정적 튜플) 노트 명시. 4종 중 이 세 가지를 한 파일에서 모두 만족하는 본은 v15뿐이다.

> 재검수 한계(정직): 아래 평가는 HTML 렌더 실측이 아니라 마크업·수치 grep + 노트 정독 기반 정적 검토다. 시각 점수(④)와 애니메이션(S2 점 누적·S3 곡선 SVG)의 실제 인상은 재형님 눈 확인 필요. 다만 수치·구조·폴백 설계는 코드 레벨에서 확인됨.

### 검토 한계 (정직)
- HTML 렌더 실측이 아닌 **마크업·수치 grep + 발표자 노트 정독 기반 정적 검토.** 시각 점수(④)·애니메이션 실제 인상은 재형님 눈 확인 필요.
- lock 수치는 v15 본문에서 24개 항목 전수 grep 통과를 확인했고, 정전 수치는 변경하지 않았다.
- "5각도"는 본 방 표준 평가축(Thesis/수치락/정직성/시각/실행). v15 추가로 "재검수" 열(수치 전수 grep)을 더했다.

## 0. 한 줄 요약 (이 문서가 강제하는 것)

> **밝은 종이(warm paper) 위 잉크블랙 타이포 + 단 하나의 시그니처 잉크(인디고) + 의미에만 쓰는 위험 3색. 에디토리얼 키노트의 여백 위에, 데이터 슬라이드는 계측기(instrument)의 정밀함으로 그린다.**

채택 방향 이름: **"Editorial Instrument" (에디토리얼 인스트루먼트)**
= Direction A(밝은 에디토리얼 키노트)를 **덱 전체 골격**으로, Direction B(계측기/과학 정밀)를 **데이터 슬라이드(S3·S4·S7·S9·S10)의 차트 규율**로 합성. Direction C(다크 키네틱)는 **채택하지 않음** — 다크 배경 자체가 빔프로젝터 가독성과 AI 클리셰 양쪽에서 불리(7절 참고). C의 입자 모션 아이디어만 "선택 1슬라이드"에서 극도로 절제해 차용 가능(5절).

## 1. 채택 디자인 방향 — 철학과 "왜 AI 클리셰를 벗는가"

### 1.1 채택: Editorial Instrument

| 축 | 결정 | 한 문장 근거 |
|----|------|-------------|
| 배경 | **밝은 warm paper** (`#F4F2EC`) | 빔프로젝터는 명암↓·거리 멀음 → 밝은 바탕+검은 글씨가 다크 테마보다 대비·가독 우위. 동시에 "AI 다크 대시보드" 클리셰를 정면 회피. |
| 액센트 | **단 하나의 시그니처 잉크** (editorial indigo `#1B3A8F`) | "5색 그라데이션"이 AI 냄새의 핵심. 액센트를 1개로 줄이면 즉시 "사람이 고른 색"으로 읽힌다. |
| 위험색 | **3색은 위험도 의미에만** (brick/amber/green) | 색을 장식이 아니라 정보로만 쓰면 위계가 살아난다. |
| 타이포 | 그로테스크 본문 + **시그니처 단어 1개만 세리프 이탤릭** | 한 슬라이드에 "공들인 한 끗" — 사람 손의 신호. |
| 데이터 | **진짜 축·눈금·CI 밴드·tabular 숫자** (B 규율) | "우리는 다 정직하게 측정했다"를 디자인으로 증명. placeholder 차트 금지. |
| 모션 | **거의 없음.** 전환 페이드 200ms, 점 누적 1회 | 모션은 정체성이 아니라 절제. 발표장에서 산만함은 독. |

### 1.2 철학 — "관점 있는 프리미엄"

이 덱의 thesis는 *"모델이 아니라 데이터 수집 인프라가 주인공"*이다. 디자인 철학은 그 thesis와 **동형**이어야 한다:

> 화려한 한 장(=모델 한 개)이 아니라, **일관된 시스템(=인프라)**이 인상을 만든다.

따라서 디자인의 무기는 "그라데이션·발광·이모지"가 아니라 **일관성·여백·위계·정밀함**이다. 슬라이드 하나가 예뻐 보이는 게 아니라, 13장이 같은 규율로 흘러 "이 팀은 시스템을 만든다"가 보여야 한다.

### 1.3 왜 이게 AI 클리셰를 벗는가 (검토관 지적 직결)

AI가 자동 생성한 덱의 5대 냄새와, 본 방향이 각각을 어떻게 끊는가:

| AI 냄새 | 왜 AI 같은가 | 본 방향의 차단 |
|---------|-------------|---------------|
| **다크 + 네온 그라데이션 카드** | LLM 기본 미감의 최빈값 | 밝은 종이 + **그라데이션 전면 금지**(평면 면색만) |
| **5색 이상 액센트** | "다채로움=풍부함" 오해 | 액센트 **1색** + 위험 3색(의미한정) = 실효 4색, 한 슬라이드엔 보통 2색 |
| **이모지 라벨(🎯🚀✨)** | 토큰 경제적 장식 | 이모지 **0개**. 강조는 타이포 굵기·잉크로만 |
| **메타라벨 남발("핵심 인사이트:", "결론:")** | 모델이 구조를 말로 때움 | 라벨은 eyebrow 1줄로 끝. 본문이 스스로 구조를 보임 |
| **평평한 위계(다 같은 크기 카드)** | 중요도 판단 회피 | 슬라이드당 **앵커 1개**(가장 큰 것 하나) + 나머지는 명확히 작게 |

## 2. 디자인 토큰 (전체)

> 모든 값은 CSS 커스텀 프로퍼티로 선언. 자립형 HTML — 외부 폰트·CDN 금지, 시스템 폴백만.

### 2.1 컬러

```css
:root{
  /* ---- 표면 (warm paper 계단) ---- */
  --paper:        #F4F2EC;  /* 슬라이드 바닥 */
  --paper-deep:   #ECE9E1;  /* 함몰 패널 / 푸터 룰 영역 */
  --surface:      #FBFAF6;  /* 카드 / 차트 플레이트(near-white) */

  /* ---- 잉크 3단 + 보조 ---- */
  --ink:          #16151A;  /* 1차 텍스트 — warm near-black */
  --ink-2:        #4B4A52;  /* 2차 텍스트 */
  --ink-3:        #8B8A90;  /* 캡션 / 축 라벨 */
  --faint:        #B7B3A8;  /* 단위 / 보조 눈금 */

  /* ---- 헤어라인 ---- */
  --rule:         #D8D4C8;  /* 1px 기본 헤어라인 */
  --rule-soft:    #E6E2D8;  /* 가장 약한 디바이더 / 마이너 그리드 */
  --rule-hard:    #C9C4B7;  /* 축 프레임(약간 진한) */

  /* ---- 시그니처: 단 하나의 액센트 (editorial indigo) ---- */
  --signature:    #1B3A8F;  /* 덱 전체의 유일한 주액센트 */
  --signature-2:  #2E55C2;  /* 채움용 틴트(드물게) */
  --signature-wash:#1B3A8F14; /* 8% 워시 — 핀 배경 등 */

  /* ---- 위험 3색: 위험도 '의미'에만. 장식 절대 금지 ---- */
  --risk-hi:      #B23A2E;  /* 고위험 / 취소 — muted brick (네온 아님) */
  --risk-mid:     #B8862B;  /* 중위험 — amber */
  --risk-lo:      #3F7A52;  /* 저위험 / 정상 — muted green */

  /* ---- 모델 시리즈 색 (의미 고정) ---- */
  --lr:           #6F6E74;  /* Logistic Regression — graphite(지는 모델) */
  --lgb:          #1B3A8F;  /* LightGBM — 시그니처 잉크(이기는 모델) */
  --dummy:        #B8B3A6;  /* Dummy baseline — neutral */
}
```

색 사용 규칙(엄수):
- 한 슬라이드에 등장하는 액센트 색은 **시그니처 1색**이 기본. 위험 3색은 "위험도를 표현하는 그 슬라이드(S5·S7·S9)"에서만 추가.
- **그라데이션 채움 금지.** 면은 평면 단색. (그림자/inset 하이라이트는 허용 — 2.5 참고)
- 시리즈 색은 의미 고정: LightGBM=시그니처 잉크(주인공), LR=graphite(조연), Dummy=neutral 점선.

### 2.2 타이포그래피

```css
/* 본문 — 정제된 그로테스크. 시스템 폴백 체인 자립 */
--font-sans: "Helvetica Neue","Segoe UI Variable Display","Pretendard",
             "Segoe UI","Apple SD Gothic Neo","Malgun Gothic",
             Roboto,Arial,sans-serif;

/* 숫자 — tabular(계측기 정밀). 차트·KPI에 강제 */
--font-mono: "JetBrains Mono","SF Mono","Roboto Mono",ui-monospace,
             "Consolas",monospace;   /* font-feature-settings:"tnum" 1 */

/* 시그니처 세리프 — 슬라이드당 '한 단어'만. 사람 손의 신호 */
--font-serif:"Iowan Old Style","Apple Garamond","Times New Roman",
             "Nanum Myeongjo","Batang",Georgia,serif;  /* italic 사용 */
```

**타입 스케일** (1280×720 스테이지 기준, px):

| 역할 | size | weight | line-height | letter-spacing | 비고 |
|------|------|--------|-------------|----------------|------|
| H1 (타이틀 슬라이드) | 56 | 700 | 1.08 | -0.025em | S1·S13만 |
| H1 (콘텐츠 헤드라인) | 44–46 | 700 | 1.10 | -0.02em | max-width 21ch |
| Dek (부제) | 19 | 400 | 1.50 | 0 | max-width 52ch, `<b>`만 650 |
| KPI 값(앵커) | 54 | 700 | 1.0 | -0.025em | tabular, 시그니처색 |
| KPI 값(보조) | 30–34 | 600 | 1.0 | -0.02em | tabular |
| 본문 리스트 | 15.5 | 400 | 1.42 | 0 | `<b>` 650 |
| Eyebrow | 14 | 600 | 1.0 | 0.16em | UPPERCASE, ink-3 |
| 차트 축 라벨 | 18 | 400 | — | 0 | mono, ink-3 |
| 차트 눈금 숫자 | 16–18 | 400 | — | -0.02em | **mono tabular** |
| 캡션 / 출처 | 13 | 400 | 1.4 | 0.01em | ink-3 |
| 푸터 thesis | 21 | 400 | 1.35 | -0.01em | `<b>`=시그니처 700 |

규율:
- **굵기는 3단만**: 400(본문)·600~650(강조)·700(헤드/KPI). 800·900 금지(둔탁·AI틱).
- 모든 숫자(KPI·축·표)는 `font-variant-numeric:tabular-nums` 강제.
- 시그니처 세리프 이탤릭은 **슬라이드당 1개 단어/구**만. 두 개 이상이면 효과 소멸.

### 2.3 간격 (4px 베이스 스케일)

```
--s1:4  --s2:8  --s3:12  --s4:16  --s5:24  --s6:32  --s7:48  --s8:64  --s9:96
```
- 슬라이드 외곽 패딩: 상 64 / 좌우 96 / 하 60 (`64px 96px 60px`). **96px 좌우 여백이 에디토리얼의 핵심** — 줄이지 말 것.
- 섹션 간 수직 간격: 헤드↔바디 8, KPI 블록 간 26, 리스트 항목 간 14.

### 2.4 반경 / 라인

```css
--r-card: 6px;   /* 카드·차트 플레이트 */
--r-chip: 3px;   /* 핀·칩 (거의 각진) */
--r-slide:4px;   /* 슬라이드 프레임 */
--hair: 1px;     /* 모든 헤어라인 기본 */
```
- 반경은 **작게**(3–6px). 큰 둥근 모서리(16–18px)는 카드형 AI 덱의 전형 → 회피.
- 축 프레임 1.4px, CI 밴드 stroke 없음(fill만), 시리즈 라인 LightGBM 4px / LR 3px / Dummy 1.4px 점선.

### 2.5 그림자 / 헤어라인 (깊이 표현)

```css
/* 슬라이드 프레임 — 종이가 떠 있는 미세한 그림자 + inset 하이라이트 */
box-shadow:
  0 1px 0 rgba(255,255,255,.6) inset,
  0 30px 80px -30px rgba(30,28,22,.28),
  0 2px 8px rgba(30,28,22,.06);

/* 카드/플레이트 — 거의 평면. inset 상단 하이라이트만 */
box-shadow: 0 1px 0 rgba(255,255,255,.7) inset;
```
규율: **컬러 글로우(box-shadow에 액센트색) 금지.** 그림자는 항상 warm-black 계열, 매우 옅게. 깊이는 그림자가 아니라 **헤어라인 + 면색 계단(paper→surface)**으로 만든다.

## 3. 레이아웃 그리드 · 투영 규칙

### 3.1 스테이지 & 그리드
- **스테이지: 1280×720 (16:9) 고정.** 16:9 빔프로젝터 표준.
- 암묵 **12컬럼 그리드**, 거터 24px. 외곽 96px 여백 안쪽에서 운용.
- 콘텐츠 슬라이드 표준 바디: `grid-template-columns: 1fr 320px` (좌=풀블리드 데이터/본문, 우=슬림 레일). 거터 48px.

### 3.2 슬라이드 골격(모든 콘텐츠 슬라이드 공통)
```
[ 시그니처 좌측 룰 6px (signature) ]  ← 덱 전체 반복 모티프 앵커
┌──────────────────────────────────────────┐
│ topbar:  eyebrow(번호·섹션)      progress  │  ← 18px 아래 마진
│ head:    H1 (+ inline pin)                 │
│          dek                               │
│ body:    [ 풀블리드 데이터 | 320px 레일 ]   │  ← flex:1
│ foot:    thesis 한 줄        ·    페이지    │  ← top rule
└──────────────────────────────────────────┘
```

### 3.3 투영/가독성 규칙 (빔프로젝터 강제)
- **최소 폰트 13px**(@1280 스테이지). 캡션·출처 외에 13px 미만 금지.
- **대비비 AA 이상**: 본문 ink(`#16151A`) on paper(`#F4F2EC`) = 약 13:1 (AAA). ink-3(`#8B8A90`) on paper ≈ 3.6:1 → **캡션/축 라벨에만** 허용, 본문 금지.
- 위험 3색은 텍스트로 쓰지 말고 **마커/면**으로. 텍스트 강조는 잉크 굵기로.
- 얇은 1px 헤어라인이 프로젝터에서 사라질 수 있음 → **축 프레임은 1.4px**, 데이터 라인은 3px 이상.
- 반응형: 스테이지를 `transform: scale()`로 뷰포트에 피팅(레터박스). 폰트는 px 고정(스테이지 단위 일관성). `@media (max-width:1100px)`에서 레일을 본문 아래로 스택(에디터 미리보기용, 발표는 항상 1280 스케일).

## 4. 컴포넌트 스펙 (정확 수치)

### 4.1 Eyebrow (상단 섹션 라벨)
- 구조: `[번호 num] [tick 26×1px] [섹션명]`. font 14 / 600 / 0.16em / UPPERCASE / ink-3.
- 번호(`.num`)는 시그니처색 700, tabular. tick은 rule 색 1px.
- **이게 유일한 메타라벨이다.** 본문에 "핵심:", "결론:" 같은 라벨 추가 금지.

### 4.2 진행 표시 (progress)
- 13개 세그먼트 dot: `13×3px`, radius 2px, 간격 6px. rule 색, 현재 슬라이드만 `.on`=시그니처색.
- 우측 라벨 `04 / 13` — 13px, 0.04em, tabular, ink-3.
- **그라데이션 progress bar 금지**(v14의 `linear-gradient(acc,vio)`가 대표적 AI 냄새).

### 4.3 헤드라인 (H1)
- 44–46px / 700 / 1.10 / -0.02em, max-width 21ch.
- 시그니처 단어: `.accent`(시그니처색) + 필요시 `.serif`(세리프 이탤릭) **하나만**.
- inline pin은 H1 끝에 붙임(4.7).

### 4.4 KPI (앵커 리딩)
- 앵커 1개: 값 54px/700/시그니처색/tabular, 단위 small 24px/650/ink-2. 라벨(`.k`) 15px/ink-2, `<b>`=ink 650.
- 보조 KPI(B 스타일 레일): 라벨 10.5px UPPERCASE ink-3 + 값 30–34px ink + sub 10.5px ink-3.
- **슬라이드당 앵커 KPI는 1개.** 나머지는 시각적으로 분명히 작게(위계).

### 4.5 카드 / 플레이트
- `--surface` 평면 면색 + `--rule-soft` 1px + radius 6px + inset 하이라이트만.
- 패딩: 차트 플레이트 18/22/12, 일반 카드 20/24.
- **그라데이션 배경·컬러 보더·글로우 금지.**

### 4.6 표 (S2 대조표·S11 집중블록)
- `border-collapse`, 행 구분은 `--rule` 1px bottom만(세로선 없음). 마지막 행 보더 제거.
- th: 12px / 600 / UPPERCASE / 0.06em / ink-3. td: 15–16px / ink-2, `<b>`=ink 700.
- 패딩 셀당 `10px 13px`. 제브라 줄무늬 금지(헤어라인으로 충분).

### 4.7 인라인 핀 (honesty pin)
- 종이톤 배지(발광 칩 아님): surface 배경 + rule 1px + **좌측 3px signature 보더** + 6px signature dot.
- font 13px / 600 / 0.02em / ink-2, padding `5px 11px`, radius 3px, `white-space:nowrap`.
- 위치: 의심이 떠오르는 그 자리(H1 끝 또는 레일). 텍스트는 design_20의 핀 문구 그대로(예: "국적 피처 윤리 → S11").

### 4.8 차트 (S4 성장곡선 = 레퍼런스 구현)
규율(B 인스트루먼트):
- **진짜 축**: Y축 PR-AUC 0.40–0.80(눈금 0.10 간격), X축 누적 학습량(주차+건 2단 라벨). 축 프레임 1.4px `--rule-hard`.
- **마이너 그리드**: 가로 헤어라인 `--rule-soft` 1px만(세로 그리드 없음).
- **CI 밴드**: fill만(stroke 없음), opacity 0.12–0.16. LightGBM=signature wash, LR=neutral wash.
- **시리즈 라인**: LightGBM 4px signature, LR 3px graphite, Dummy 1.4px neutral 점선(`2 5`).
- **tie 음영**: CI 겹치는 구간을 `#16151A` opacity 0.035 사각형 + 이탤릭 캡션 "구분 불가 (tie · CI 겹침)". **"교차"라는 단어 금지**(design_20 §6 락).
- **W 마커**: 전환점 수직 점선 signature(opacity 0.55) + 7px 원(흰 테두리 2.5px) + 콜아웃 "W ≈ 5.4만 건 / 여기서 추월 — 끝까지 유지".
- **끝점 라벨**: tabular, "LightGBM · 0.820" / "LR · 0.78". 출처 캡션 13px ink-3: "실데이터 — Kaggle, 우리 두 호텔의 실제 2년 기록(City 리스본·Resort 알가르브) · Bootstrap 95% CI · 하이쿠 미사용".
- 모든 차트 숫자 mono tabular. **placeholder 곡선이라도 형태는 RM/성장 이론을 따르고, 값은 design_20 정전값으로 고정.**

### 4.9 범례 (legend)
- 가로 배치, 항목 간 24px. 스와치: 라인=16×2.5px, 점선=border-top dashed, 면=14×14 radius 3px.
- 12–13px / ink-2. 위험 3색 범례는 위험 슬라이드에서만.

### 4.10 발표자 멘트(🎤) / 정직 각주
- 좌측 2px signature 보더 + padding-left 16px. 14px / ink-3 / italic, `<b>`=ink-2 normal.
- 🎤 텍스트는 design_20 §2의 멘트 그대로. 화면엔 짧은 버전, 풀텍스트는 발표자 노트(N키 오버레이)로.

### 4.11 푸터 thesis

## 5. 시그니처 모티프 · 모션 · 인터랙션

### 5.1 시그니처 모티프 — "왼쪽 잉크 룰"
- 모든 슬라이드 좌측 끝 **6px 세로 signature 룰**(`.slide::before`). 덱을 하나로 묶는 반복 앵커.
- 보조 모티프: KPI/핀의 좌측 3px signature 액센트(같은 룰의 미니 버전).
- **이 룰 하나가 덱의 정체성.** 슬라이드마다 다른 장식을 넣지 말 것.

### 5.2 모션 원칙 (절제)
- 슬라이드 전환: opacity 페이드 **200–280ms ease**만. 슬라이드 인/슬라이드 아웃·줌·플립 금지.
- **딱 두 곳에서만 모션 허용**:
  1. **S3 점 누적**: 채널칩에서 수집구로 점이 1회 쌓이는 애니메이션(정상 녹색/취소 brick). `prefers-reduced-motion` 존중, 6–10초 내 완료 후 정지.
  2. **S10 데모**(라이브/녹화)는 콘텐츠 자체가 모션.
- C방향의 입자 캔버스는 **채택 안 함**(밝은 종이에선 입자가 지저분·산만). 굳이 쓰면 S3 한정·opacity 0.06 이하·정지 프레임 위주.
- 차트 라인 draw-on 애니메이션: 선택. 쓰면 S4에서만, 500ms 이내, 1회.

### 5.3 인터랙션 / 네비
- 키: `← →` 이동, `F` 전체화면, `N` 발표자 노트 오버레이.
- 발표자 노트: 하단에서 슬라이드업하는 오버레이(transform translateY), 본문 가리지 않게 반투명 페이퍼. 라벨 12px/0.18em UPPERCASE/signature.
- 진행바·페이지 카운트는 고정(우하단), ink-3.

## 7. 피해야 할 AI 냄새 체크리스트 (출고 전 검수)

발표 직전 각 슬라이드를 이 목록으로 통과시킨다. **하나라도 걸리면 수정.**

배경·색
- [ ] 다크 네이비/차콜 배경 + 네온 액센트 조합이 있는가 → **있으면 탈락**(밝은 paper로)
- [ ] 카드/버튼/바에 `linear-gradient`(컬러→컬러)가 있는가 → **전면 금지**
- [ ] 한 슬라이드에 액센트 색이 3색 이상인가(위험3색은 의미슬라이드 예외) → 줄여라
- [ ] box-shadow에 컬러 글로우(`rgba(accent,…)`)가 있는가 → warm-black으로
- [ ] progress bar가 무지개/2색 그라데이션인가 → 단색 세그먼트로

타이포·라벨
- [ ] 이모지가 1개라도 있는가(🎯🚀✨💡🔥📊) → **0개로**
- [ ] "핵심 인사이트:", "결론:", "요약:" 같은 메타라벨이 본문에 있는가 → eyebrow로 흡수
- [ ] 폰트 굵기 800/900을 본문/헤드에 썼는가 → 700 상한
- [ ] 숫자가 비례폭(non-tabular)으로 흔들리는가 → tabular 강제
- [ ] 시그니처 세리프를 슬라이드당 2개 이상 썼는가 → 1개로

위계·레이아웃
- [ ] 같은 크기 카드가 4–6개 평평하게 깔렸는가(앵커 없음) → 앵커 1개 키우기
- [ ] 좌우 여백이 96px보다 좁아 빽빽한가 → 여백 확보
- [ ] 큰 둥근 모서리(≥14px)가 카드형 AI 느낌을 주는가 → 3–6px로
- [ ] 모든 슬라이드가 "제목+불릿 3개" 동일 틀인가 → S4/S7/S11은 데이터/표 주도로 차별화

데이터 정직
- [ ] 차트가 축·눈금 없는 장식 곡선(placeholder)인가 → 진짜 축+눈금+출처 캡션
- [ ] CI 겹침을 "교차/추월"로 표기했는가 → "tie(구분 불가)" (design_20 §6 락)
- [ ] 수치가 design_20 §6 락과 불일치하는가 → 락이 기준, 즉시 수정

## 8. Claude Design 복붙 프롬프트 (자립형)
